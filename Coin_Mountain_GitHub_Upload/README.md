# Coin Mountain: Ascension — Network Build Project

This project preserves the latest Premium Visual Overhaul gameplay and prepares a reproducible build that bundles the **official Three.js 0.160.0** package locally. The project source refers to `three` as an npm dependency; Vite bundles that package into `dist/assets/` during the build. The resulting `dist/` is the offline-capable web build (browser storage still saves progress per browser).

## Build details
- Runtime: Three.js **0.160.0** (exact pinned version)
- Build tool: Vite **5.4.14** (exact pinned version)
- Node: 20
- No Three.js addons are currently imported. If added later, use the same `three@0.160.0` package and import addons from that same package version.

## Automated cloud build
The included GitHub Actions workflow runs on pushes to `main`/`master` and can also be started manually. It installs the pinned dependencies from the npm registry, builds the production bundle, runs source checks and the existing gameplay regression suite, then uploads the production `dist/` as a downloadable workflow artifact. This uses GitHub's network-enabled runners rather than this isolated workspace.

## What is and is not already bundled
- `src/main.js` imports the official package by its package name; the package source is intentionally not faked or copied from the test mock.
- `package.json` pins `three` to `0.160.0`; the real package is downloaded by npm in the network-enabled build runner.
- `dist/` is generated by the workflow and is **not included in this source archive**, because this isolated environment cannot fetch the npm package. Do not call this source ZIP a self-contained game. The workflow artifact is the actual bundled game once the cloud build succeeds.
- `preserved-builds/` holds copies of previous standalone HTML builds. `game-reference.html` is the latest source used for baseline regression.
- `tests/mock_three.js` is only for logic regression testing; it is not a runtime engine and is never imported by the production game.

## Local gameplay data
The game stores save data in the browser's localStorage. Browser saves do not automatically migrate between different origins (e.g., a local file and a hosted site).
